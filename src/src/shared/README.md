# shared (공통 모듈)

## 개요

전체 앱에서 공유되는 유틸리티, API 클라이언트, UI 컴포넌트, 훅을 제공합니다.

## 하위 구조

- `api/` - Axios 클라이언트, GTFS API 클라이언트
- `ui/` - 공통 UI 컴포넌트 (Button, Card, Modal 등)
- `hooks/` - 공통 훅 (useLocation, useNetworkStatus 등)
- `lib/` - 유틸리티 (notifications, geofence, storage)
- `constants/` - 상수 정의
