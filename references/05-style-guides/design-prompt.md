# Getting Off - UI/UX 디자인 프롬프트

## 앱 개요

"Getting Off"는 직장인을 위한 출퇴근 교통 알림 앱입니다. 지하철과 버스를 이용하는 수도권 직장인이 출퇴근 경로를 저장하고, "출퇴근 시작" 버튼 하나로 정거장 알림, 하차 알림, 환승 안내를 자동으로 받을 수 있습니다.

- 플랫폼: iOS + Android (React Native)
- 타겟 유저: 20~40대 수도권 직장인
- 벤치마킹: "이번정류장" 앱 (thisstop.co.kr)
- 차별점: 지하철+버스 통합, 경로 저장, 환승 도보 시간 고려
- 디자인 톤: 깔끔하고 직관적, 최소한의 조작, 출퇴근 중 한 손 조작 가능

---

## 디자인 방향

### 키워드
- 심플, 직관적, 정보 밀도 높음, 한 손 조작, 다크모드 친화
- 카드 기반 UI, 큰 터치 타겟, 명확한 상태 표시
- 브랜드 컬러: 파랑(#1A73E8) + 흰색 기반, 포인트: 초록(버스), 빨강(알림/하차)

### 컬러 시스템
| 용도 | 컬러 |
|------|------|
| 프라이머리 (지하철/메인) | #1A73E8 |
| 버스 | #34A853 |
| 경고/하차 | #E53935 |
| 환승/접근 | #FFB300 |
| 도보 | #999999 |
| 배경 | #F5F5F5 (라이트) / #121212 (다크) |
| 카드 배경 | #FFFFFF (라이트) / #1E1E1E (다크) |
| 텍스트 | #333333 / #666666 / #999999 |

### 타이포그래피
- 제목: 20~28px, Bold
- 본문: 14~16px, Regular/Medium
- 보조: 11~13px, Regular
- 숫자 강조 (소요시간 등): 22~28px, Bold

## 화면 구성 (총 5개)

### 1. 홈 화면 (메인)

**목적**: 저장된 경로 목록 표시, 출퇴근 빠른 시작

**구성 요소**:
- 상단 헤더: 앱 로고 "Getting Off" + 설정 아이콘
- 저장된 경로 카드 리스트 (세로 스크롤)
  - 각 카드: 경로명 (예: "강남역 → 시청역"), 소요시간, 노선명, 환승 횟수, 요금
  - 카드 탭 → 출퇴근 시작 확인 다이얼로그
  - 카드 스와이프 또는 삭제 버튼
- 경로가 없을 때: 빈 상태 일러스트 + "경로를 탐색하고 저장해보세요" 안내
- 하단 플로팅 버튼: "+ 경로 탐색"

**UX 포인트**:
- 가장 최근 사용한 경로가 상단에 (최신순)
- 카드 탭 한 번 → 확인 → 바로 출퇴근 시작 (최소 2탭)
- 출퇴근 시간대에는 자주 쓰는 경로를 하이라이트

---

### 2. 경로 탐색 화면

**목적**: 출발지/도착지 검색 → 경로 결과 선택 → 저장

**구성 요소**:
- 상단 입력 영역 (카드)
  - 출발지 입력 필드 (라벨: "출발", 플레이스홀더: "역/정류장명 입력")
  - 도착지 입력 필드 (라벨: "도착", 플레이스홀더: "역/정류장명 입력")
  - 출발↔도착 교환 버튼 (가운데 위치)
  - 입력 시 실시간 자동완성 드롭다운 (역/정류장 목록, 지하철/버스 구분 태그)
- "경로 검색" 버튼 (양쪽 선택 완료 시 활성화)
- 검색 결과 리스트 (세로 스크롤)
  - 각 결과 카드: 경로 유형 태그 (지하철/버스/복합), 총 소요시간 (크게), 노선 요약 (예: "2호선 > 도보 > 143번"), 환승 횟수, 요금, 도보 시간
  - 카드 탭 → "이 경로를 저장하시겠습니까?" 다이얼로그

**UX 포인트**:
- 자동완성은 2글자 이상 입력 시 표시
- 검색 결과는 소요시간 순 정렬
- 결과 카드에서 각 구간(도보/지하철/버스)을 색상 점으로 시각화

---

### 3. 출퇴근 화면 (핵심)

**목적**: 출퇴근 진행 상태 실시간 표시, 정거장 감지, 알림

**구성 요소**:
- 상단 헤더 (프라이머리 컬러 배경)
  - 경로명 (예: "강남역 → 시청역")
  - 요약 정보: 총 소요시간 | 요금 | 환승 횟수
  - GPS 상태 표시 (초록 점 = 추적 중, 주황 = 대기)
- 정거장 감지 배너 (조건부 표시)
  - 접근 중: 노란 배경 + "OO 부근입니다. N정거장 남음"
  - 도착: 초록 배경 + "OO에 도착했습니다"
  - 큰 텍스트로 현재 정거장명, 남은 정거장 수, 거리
- 환승 안내 배너 (조건부 표시)
  - 노란 보더 카드
  - "OO에서 하차 → 도보 약 N분 → OO에서 XX 탑승"
  - 단계별 시각화 (빨간 점 → 주황 도보 선 → 파란 점)
- 실시간 도착정보 카드 (조건부 표시)
  - 현재 구간의 정류소/역 도착정보
  - 노선명, 행선지, 도착 메시지
  - 곧 도착: 빨간 강조
- 경로 상세 (접기/펼치기)
  - 전체 구간 목록 (도보/지하철/버스)
  - 현재 구간 하이라이트, 지나간 구간 회색
- 경로 타임라인 (메인 콘텐츠)
  - 세로 타임라인 UI (왼쪽 점 + 선, 오른쪽 구간 카드)
  - 각 구간: 교통수단 색상 점, 노선명, 출발→도착, 소요시간, 정거장 수
  - 현재 구간: 노란 보더 + "현재 구간" 태그
  - 지나간 구간: 회색 처리
- 하단 "출퇴근 종료" 버튼 (빨간색, 확인 다이얼로그)

**UX 포인트**:
- 화면 상단에 가장 중요한 정보 (현재 정거장, 남은 수) 집중
- 뒤로가기/제스처 비활성화 (실수로 종료 방지)
- 알림 배너는 상태에 따라 자동 표시/숨김
- 타임라인은 현재 구간이 항상 보이도록 자동 스크롤

---

### 4. 설정 화면

**목적**: 앱 동작 커스터마이징

**구성 요소**:
- 섹션 1: 보행 속도
  - 라디오 선택: 느리게 (0.8 m/s) / 보통 (1.2 m/s) / 빠르게 (1.6 m/s)
- 섹션 2: 하차 알림 타이밍
  - 라디오 선택: 1~5 정거장 전
- 섹션 3: 알림
  - 토글: 알림 소리 ON/OFF
  - 토글: 진동 ON/OFF
- 하단: 앱 버전 표시

**UX 포인트**:
- iOS 스타일 그룹 리스트
- 선택된 옵션에 체크마크
- 변경 즉시 반영 (저장 버튼 불필요)

---

### 5. 경로 상세 / 경로 저장 확인 (모달 또는 바텀시트)

**목적**: 선택한 경로의 상세 정보 확인 후 저장

**구성 요소**:
- 경로 요약: 출발 → 도착, 총 소요시간, 요금
- 구간별 타임라인 (축약 버전)
- "저장" / "취소" 버튼

---

## 아이콘 및 일러스트

- 교통수단 아이콘: 지하철 (동그라미 + 번호), 버스 (버스 모양), 도보 (사람)
- 상태 아이콘: GPS 추적 (초록 점), 알림 (종 모양), 설정 (톱니바퀴)
- 빈 상태 일러스트: 경로가 없을 때 부드러운 라인 일러스트

---

## 반응형 고려사항

- 최소 지원 화면: iPhone SE (375px 너비)
- 큰 화면 (태블릿): 카드 최대 너비 제한 (480px)
- 노치/다이내믹 아일랜드: SafeArea 대응
- 한 손 조작: 주요 버튼은 화면 하단 배치
