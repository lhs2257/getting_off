# 공공 교통 API 리서치

| API | 버스 실시간 | 지하철 실시간 | 경로 탐색 | 지역 | 무료 제한 |
|-----|:---:|:---:|:---:|------|----------|
| 서울열린데이터광장 | O | O | O | 서울 | 1,000건/일 |

## 권장 API 조합 A: 수도권 집중

| 역할 | 사용 API | 이유 |
|------|----------|------|
| 서울 버스 실시간 | 서울열린데이터광장 | 데이터 품질 최상 |
| 서울 지하철 실시간 | 서울열린데이터광장 | 전 노선 커버 |
| 경기 버스 실시간 | GBIS API | 경기도 + 서울 진출입 노선 |
| 경로 탐색/환승 | ODsay API | 복합 경로 계산 특화 |

## 권장 API 조합 B: 전국 대응

| 역할 | 사용 API | 이유 |
|------|----------|------|
| 전국 버스 실시간 | TAGO API | 전국 유일 공공 API |
| 서울 지하철 실시간 | 서울열린데이터광장 | TAGO 지하철 데이터 미흡 |
| 경로 탐색/환승 | ODsay API | 전국 노선 DB 및 경로 계산 |

## 호출 제한 대응

- 개발 단계: 각 API 무료 제한으로 충분
- 서비스 출시 후: 활용사례 등록으로 제한 해제 신청, ODsay는 유료 전환 고려

## 상세 API 정보

### 서울열린데이터광장 (data.seoul.go.kr)

- 버스도착정보, 버스위치정보, 버스노선정보, 버스정류소정보
- 지하철 실시간 도착정보, 지하철 실시간 열차 위치정보
- 대중교통 환승경로 조회
- 서울특별시 전용

### TAGO API (data.go.kr)

- 버스위치정보, 버스도착정보, 버스노선정보, 버스정류소정보
- 지하철역정보, 지하철시간표
- 전국 단위, 지자체별 데이터 품질 편차 존재
- 기존 API 13종 폐기 후 신규 API로 대체 운영 중

### ODsay API (lab.odsay.com)

- 대중교통 경로 탐색, 실시간 버스 위치/도착정보
- 지하철 시간표, 지하철 경로 탐색
- Basic(무료 6개월, 1,000건/일) / Standard(유료, 100,000건/일)
